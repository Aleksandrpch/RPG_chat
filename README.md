## 📱 Экраны приложения
1. Главный экран (CharacterSelectScreen)
Отображает список всех созданных персонажей
Каждый персонаж представлен карточкой с аватаром, именем, классом и временем последней игры
Если список пуст, отображается кнопка для создания первого персонажа
Плавающая кнопка «+» для быстрого создания нового персонажа

2. Экран создания персонажа (CreateCharacterScreen)
Аватар: генерация изображения персонажа с возможностью выбора визуального стиля
Визуальное описание: текстовое поле для описания внешности (цвет волос, глаз, одежда и т.д.)
Визуальный стиль: выбор из 5 предустановленных стилей (Аниме, Синема, Dark Fantasy, Cyberpunk, Акварель) + возможность указать свой вариант
Имя персонажа: обязательное текстовое поле
Предыстория: текстовое поле для описания истории персонажа (обязательное)
Сюжет на основе лора: чекбокс, определяющий, будет ли сюжет учитывать мифологию мира
Способности: два поля для указания уникальных навыков персонажа
Достижения: два поля для указания полученных достижений
Кнопка «Дополнить пустые поля» — автоматическая генерация недостающих данных через ИИ
Кнопка «Создать персонажа» — финальное сохранение и переход к выбору персонажа

3. Экран чата (ChatScreen)
Основной игровой экран
Отображение истории диалога с ИИ-рассказчиком
Поле ввода для свободных действий игрока
Поддержка вложенных изображений для ключевых событий
Автоматическая прокрутка к последнему сообщению
Кнопка для перехода к Roadmap (ключевые события)

4. Экран Roadmap (ачивки и события)
Отображение ключевых сюжетных событий
Список полученных достижений
Прогресс прохождения сюжетных арок

5. Экран настроек (SettingsScreen)
Настройки API подключения
Управление параметрами генерации (температура, max_tokens)
Экспорт истории чата
Очистка истории


## 🔧 Технические детали

### Зависимости
```yaml
dependencies:
  flutter: sdk
  flutter_localizations: sdk
  cupertino_icons: ^1.0.8
  http: ^1.2.1                 # HTTP запросы к API
  provider: ^6.1.2             # Управление состоянием
  shared_preferences: ^2.2.2   # Локальное хранение настроек
  path_provider: ^2.1.2        # Пути к файлам
  sqflite: ^2.3.2             # SQLite база данных
  sqflite_common_ffi: ^2.3.2+1 # SQLite для desktop
  google_fonts: ^6.2.1         # Шрифты Google
  intl: ^0.20.2               # Интернационализация
  path: ^1.9.0                # Работа с путями
  fl_chart: ^0.65.0           # Графики и диаграммы
```

### Поддерживаемые платформы
- ✅ Android (API 21+)
- ✅ Windows (10+)
- ⚠️ iOS (требует настройки)
- ⚠️ Linux (экспериментально)

### Управление состоянием
- **Provider** для управления состоянием чата
- **SharedPreferences** для хранения настроек API
- **SQLite** для локального хранения истории сообщений
- **Singleton** паттерн для API клиента

### Локализация
- Русский язык
- Поддержка UTF-8 для корректного отображения текста
